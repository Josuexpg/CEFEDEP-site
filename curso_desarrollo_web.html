Ingeniería y Tecnologías

Desarrollo Web (HTML5 & CSS3)

Diseña, estructura y despliega interfaces modernas y responsivas con estándares de la industria.

Duración Total

40 Horas (20t / 20p)

Modalidad

100% Virtual

Público Objetivo

Jóvenes y Adultos

Requisito

Título de Bachiller

Objetivo del Curso: Diseñar, estructurar y desplegar sitios web estáticos y responsivos utilizando HTML5 y CSS3 junto con herramientas de control de versiones y servidores de alojamiento gratuito.

Estructura del Programa (Temario)

1Fundamentos de la Web y Arquitectura Cliente-Servidor
  • ¿Cómo funciona el internet? El modelo Cliente-Servidor.
  • Roles en el desarrollo: Frontend vs. Backend vs. Fullstack.
  • ¿Qué es un navegador web y cómo interpreta el código?
  • Herramientas de trabajo: Editores de código (VS Code) y extensiones.
2Estructura Web con HTML5
  • Introducción a HTML5, sintaxis de etiquetas y estructura semántica.
  • Elementos de contenido: Títulos, párrafos, listas, enlaces e imágenes.
  • Formularios y elementos de entrada de datos.
3Estilos y Estética con CSS3
  • Introducción a CSS3: Selectores, propiedades y valores.
  • El Modelo de Caja (Box Model): Margin, Border, Padding.
  • Colores, tipografías y propiedades de texto básicas.
4Diseño Responsivo y Layouts Modernos
  • Concepto de Diseño Web Responsivo (RWD).
  • Introducción a Flexbox: Alineación y distribución.
  • Uso de Media Queries para adaptación móvil y escritorio.
5Control de Versiones y Despliegue en la Nube
  • Introducción al control de versiones (Git y GitHub).
  • Publicación del sitio web en entornos reales (ej. GitHub Pages o Netlify).
  • Buenas prácticas de optimización de recursos web.

Metodología de Estudio

  • Clase Magistral Síncrona:
    Uso de pizarras virtuales para diagramar estructuras del DOM y el Modelo de Caja.
  • Live Coding:
    Asimilación de lógica de escritura y corrección de errores en tiempo real.

Entorno de Aprendizaje

  • Software Local:
    Visual Studio Code y navegadores web modernos (Chrome/Firefox/Edge).
  • Gestión de Entregas:
    Google Classroom y despliegue final en alojamiento Cloud.

Competencias Transversales

Desarrollarás un enfoque meticuloso para identificar fallos menores de sintaxis y la habilidad visual para descomponer interfaces complejas en bloques jerárquicos simples.
